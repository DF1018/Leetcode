```python
class Solution:
    def combinationSum2(self, candidates: List[int], target: int) -> List[List[int]]:
        candidates.sort()
        res = []

        def dfs(i, cur, total):
            if total == target:
                res.append(cur.copy())
                return

            if i >= len(candidates) or total > target:
                return
            
            # include candidates[i]
            cur.append(candidates[i])
            dfs(i + 1, cur, total + candidates[i])
            cur.pop()

            # skip candidates[i]
            # [1,1,1,1,2] 
            while i + 1 < len(candidates) and candidates[i] == candidates[i + 1]:
                i += 1
            dfs(i + 1, cur, total)

        dfs(0, [], 0)
        return res
```

用途：
在 skip 分支中，跳過後面所有相同數字，
避免同一層 DFS 用相同值重複當起點，
從而產生重複組合。

例如:
```
[1,1,1,2]
 ⭡
 i
```

### skip candidates[i] 時：

* 發現後面還是 `1`
* 一直往後跳
* 直到遇到不同的數字（`2`）

最後 `i` 會直接跳到最後一個 `1`
