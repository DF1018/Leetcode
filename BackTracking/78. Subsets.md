```python
class Solution:
    def subsets(self, nums: List[int]) -> List[List[int]]:
        res = []

        subset = []
        def dfs(i):
            if i >= len(nums):
                res.append(subset.copy()) # 因為 subset 之後會被修改，所以要加上 .copy()
                return 

# ---------- 選 nums[i] ----------
            subset.append(nums[i]) # 把 nums[i] 放進子集合
            dfs(i + 1)             # 繼續考慮下一個元素

# ---------- 不選 nums[i] ----------
            subset.pop()           # 回溯，拿掉剛剛選的 nums[i]
            dfs(i + 1)             # 繼續考慮下一個元素
        
        dfs(0)
        return res
```

---

## 為什麼 Backtracking 要用 `.copy()`

在 backtracking 題目中（如 `subsets`），
`subset` 是同一個 list，會在 DFS 過程中反覆被修改：

```python
subset.append(x)
dfs(...)
subset.pop()
```

如果直接寫：

```python
res.append(subset)
```

實際存進 `res` 的只是 **同一個 list 的參考**，
之後 `subset` 被修改時，`res` 裡的內容也會一起改變。

---

## 簡易例子（nums = [1]）

### ❌ 不用 `.copy()`

```python
subset = []

subset.append(1)
res.append(subset)   # res = [[1]]

subset.pop()
res.append(subset)   # res = [[], []]  ← 錯誤
```

最終結果：

```python
res = [[], []]
```

---

### ✅ 使用 `.copy()`

```python
subset.append(1)
res.append(subset.copy())  # res = [[1]]

subset.pop()
res.append(subset.copy())  # res = [[1], []]
```
