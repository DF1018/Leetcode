```python
class Solution:
    def exist(self, board: List[List[str]], word: str) -> bool:
        ROWS, COLS = len(board), len(board[0])
        path = set()

        def dfs(r, c, i):
            if i == len(word):
                return True
            
            if (r < 0 or c < 0 or
                r >= ROWS or c >= COLS or
                word[i] != board[r][c] or
                (r, c) in path):
                return False

            path.add((r, c))
            res = (dfs(r + 1, c, i + 1) or
                   dfs(r - 1, c, i + 1) or
                   dfs(r, c + 1, i + 1) or
                   dfs(r, c - 1, i + 1))
            
            path.remove((r, c))
            return res
        
        for r in range(ROWS):
            for c in range(COLS):
                if dfs(r, c, 0): return True
        
        return False
```

---

## 📝 79. Word Search — DFS + Backtracking 筆記

### 題目核心

> 在字母矩陣中，
> 能否用 **上下左右相鄰** 的格子，
> 組成指定字串 `word`，
> **同一條路徑中，每個格子只能使用一次**。

---

## 一、整體思路

### 兩層結構

1. **外層**：遍歷整個 board，找可能的起點
2. **內層**：從某個起點，用 DFS 嘗試拼出 `word`

---

## 二、DFS 在做什麼？

DFS 函數代表的意義是：

> **從 `(r, c)` 開始，
> 能不能成功匹配 `word[i:]`？**

```python
dfs(r, c, i)
```

### 參數意義

* `r, c`：目前在 board 的位置
* `i`：目前要匹配 `word[i]`

---

## 三、終止條件（非常重要）

### ✅ 成功條件

```python
if i == len(word):
    return True
```

代表整個 `word` 都已經成功匹配。

---

### ❌ 失敗條件（剪枝）

只要符合其中一個，就直接失敗：

* 超出邊界
* 字母不相等
* 這個格子已經在目前路徑中用過

```python
if (r < 0 or c < 0 or
    r >= ROWS or c >= COLS or
    word[i] != board[r][c] or
    (r, c) in path):
    return False
```

---

## 四、為什麼需要 `path`？

```python
path = set()
```

用途：

> **避免同一條 DFS 路徑中重複使用同一個 cell**

* 進 DFS → 加入 `(r, c)`
* 出 DFS → 移除 `(r, c)`

這就是 **Backtracking 的狀態還原**

---

## 五、DFS 的核心流程

```python
path.add((r, c))

res = (
    dfs(r + 1, c, i + 1) or
    dfs(r - 1, c, i + 1) or
    dfs(r, c + 1, i + 1) or
    dfs(r, c - 1, i + 1)
)

path.remove((r, c))
return res
```

### 重點說明

* 四個方向只要有一個成功就回傳 `True`
* `path.remove()` 一定要做，否則會污染其他路徑

---

## 六、外層為什麼要掃整個 board？

```python
for r in range(ROWS):
    for c in range(COLS):
        if dfs(r, c, 0):
            return True
```

因為：

* 起點不一定在 `(0,0)`
* **任何等於 `word[0]` 的格子都可能是起點**

---

## 七、這題的本質（請背）

> **79. Word Search
> = 對每個可能起點做 DFS
>
> * 用 backtracking 控制路徑
> * 用剪枝避免爆炸**

---

## 八、常見錯誤提醒

❌ 忘記還原 `path`
→ 其他路徑被錯誤封鎖

❌ DFS 沒有先檢查字母
→ 多餘搜尋，容易 TLE

❌ 沒處理邊界
→ Runtime Error
