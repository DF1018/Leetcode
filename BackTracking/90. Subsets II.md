## neetcode

```python
class Solution:
    def subsetsWithDup(self, nums: List[int]) -> List[List[int]]:
        nums.sort()
        res = []

        def backtrack(i, subset):
            if i == len(nums):
                res.append(subset.copy())
                return
            
            # All subset that include nums[i]
            subset.append(nums[i])
            backtrack(i + 1, subset)
            subset.pop()

            # All subset that don't include nums[i]
            while i + 1 < len(nums) and nums[i] == nums[i + 1]:
                i += 1
            backtrack(i + 1, subset)

        backtrack(0, [])
        return res
```

## Subset I 的答案 + 同層去重 + 元素排序
```python
class Solution:
    def subsetsWithDup(self, nums: List[int]) -> List[List[int]]:
# ---------- 元素排序 ----------
        nums.sort()

        res = []
        subset = []
        
        def dfs(i):
            if i >= len(nums):
                res.append(subset.copy()) # 因為 subset 之後會被修改，所以要加上 .copy()
                return 

# ---------- 選 nums[i] ----------
            subset.append(nums[i]) # 把 nums[i] 放進子集合
            dfs(i + 1)             # 繼續考慮下一個元素

# ---------- 不選 nums[i] ----------
            subset.pop()           # 回溯，拿掉剛剛選的 nums[i]

# ---------- 同層去重 --------------
            while i + 1 < len(nums) and nums[i] == nums[i + 1]:
                i += 1

            dfs(i + 1)             # 繼續考慮下一個元素
        
        dfs(0)
        return res
```

## 📝 筆記一：Subsets II 要不要把 `subset` 傳進 DFS？

### 結論

> **Subsets II 傳不傳 `subset` 都可以，
> 正確性完全一樣。**

### 為什麼？

* 在 Python 中，`list` 是 **mutable object**
* 不論是：

  * 使用外層的 `subset`（closure）
  * 或把 `subset` 當參數傳入 DFS
* **操作的都是同一個 list reference**

### 兩種寫法本質對照

**不傳 `subset`（Subsets I 常見）**

```python
subset = []

def dfs(i):
    subset.append(nums[i])
    dfs(i+1)
    subset.pop()
```

**傳 `subset`（Subsets II 常見）**

```python
def dfs(i, subset):
    subset.append(nums[i])
    dfs(i+1, subset)
    subset.pop()
```

👉 兩者在記憶體層級完全相同
👉 只是「隱式共享」vs「顯式傳遞」

### 為什麼 Subsets II 常看到「傳 subset」？

* 邏輯較複雜（排序、去重）
* 傳參數可讓「當前狀態」更清楚
* 跨語言（Java / C++）寫法一致

> **是否傳 `subset` 是風格選擇，不是演算法必要條件**

## 📝 筆記二：Subsets II 的「同層去重」邏輯（最重要）

### 問題本質

> `nums` 可能有重複值，但結果不能有重複子集合。

### 必做前置

```python
nums.sort()
```

👉 讓相同值站在一起，才能被跳過。

---

### 去重原則（一句話）

> **只在「同一層 DFS」中，
> 相同的值只能當一次起點。**

---

### 為什麼只在「不選」分支跳過？

* **選分支（include）**

  * 代表「跨層選擇」
  * `[2,2]` 是合法子集合
  * ❌ 不能跳過

* **不選分支（exclude）**

  * 代表「這一層不選這個值」
  * 那同層後面相同的值也不該再當起點
  * ✅ 必須跳過

---

### 正確去重寫法（Subsets I 風格）

```python
# 不選 nums[i]
while i + 1 < len(nums) and nums[i] == nums[i + 1]:
    i += 1
dfs(i + 1)
```

### 這段在做什麼？

* 跳過「同一層」後面所有相同值
* 避免用相同值重複產生一樣的子集合
* 但不影響「跨層選到重複值」的合法結果

---

### 常見錯誤（請避開）

❌ 把 while 放在 dfs 一開始
→ 會跳掉合法的 `[2,2]`

❌ 沒排序就做 while
→ 重複值不相鄰，去重失效

---

## 🧠 最終一句話總結（強烈建議背）

> **Subsets II 的關鍵不是「傳不傳 subset」，
> 而是「同層去重，只在不選分支跳過相同值」。**
