```python
class Solution:
    def subsetsWithDup(self, nums: List[int]) -> List[List[int]]:
        nums.sort()
        res = []


        def backtrack(i, subset):
            if i == len(nums):
                res.append(subset.copy())
                return
            
            # All subset that include nums[i]
            subset.append(nums[i])
            backtrack(i + 1, subset)
            subset.pop()

            # All subset that don't include nums[i]
            while i + 1 < len(nums) and nums[i] == nums[i + 1]:
                i += 1
            backtrack(i + 1, subset)

        backtrack(0, [])
        return res
```

### Subset I 的答案 + 同層去重 + 元素排序
```python
class Solution:
    def subsetsWithDup(self, nums: List[int]) -> List[List[int]]:
# ---------- 元素排序 ----------
        nums.sort()
        res = []
        subset = []
        
        def dfs(i):
            if i >= len(nums):
                res.append(subset.copy()) # 因為 subset 之後會被修改，所以要加上 .copy()
                return 

# ---------- 選 nums[i] ----------
            subset.append(nums[i]) # 把 nums[i] 放進子集合
            dfs(i + 1)             # 繼續考慮下一個元素

# ---------- 不選 nums[i] ----------
            subset.pop()           # 回溯，拿掉剛剛選的 nums[i]

# ---------- 同層去重 --------------
            while i + 1 < len(nums) and nums[i] == nums[i + 1]:
                i += 1

            dfs(i + 1)             # 繼續考慮下一個元素
        
        dfs(0)
        return res
```

---

> **「要不要把 `subset` 傳進下一層」只是寫法不同，
> 本質都是在用同一個「當前路徑」做回溯。**

Subsets I 沒傳，是用「外部共享變數」
Subsets II 傳了，是用「顯式參數」
**演算法完全一樣，只有風格差別。**

---

## 先對照兩種寫法的本質

### ① Subsets I：不傳 `subset`

```python
subset = []

def dfs(i):
    subset.append(nums[i])
    dfs(i+1)
    subset.pop()
```

這裡的 `subset` 是：

* **外部變數（closure / shared state）**
* 每一層 DFS 都在改「同一個 subset」
* Python 允許內層函式直接用外層的變數

👉 **subset 沒傳，但它一直存在，而且一直被用**

---

### ② Subsets II：把 `subset` 當參數傳

```python
def backtrack(i, subset):
    subset.append(nums[i])
    backtrack(i+1, subset)
    subset.pop()
```

這裡的 `subset` 是：

* **顯式參數**
* 傳的是「同一個 list 的 reference」
* 行為跟外部變數版完全一樣

👉 **只是把「隱式使用」改成「顯式傳遞」**

---

## 重點：傳不傳，subset 都是「同一個 list」

很多人誤會這點，以為：

> 傳參數 = 會複製一份 subset

❌ 不對

在 Python 裡：

```python
backtrack(i, subset)
```

傳的是 **reference（參考）**，不是 copy。

所以這兩種寫法在記憶體層級其實是：

```
dfs → 用 subset
dfs → 傳 subset
```

👉 **指向的都是同一個 list**

---

## 那為什麼 Subsets II 常看到「傳 subset」？

### 原因 1️⃣：語意更清楚（工程風格）

Subsets II 有這行：

```python
backtrack(i, subset)
```

搭配：

```python
while i+1 < n and nums[i] == nums[i+1]:
    i += 1
```

這時：

* `subset` 是「這一條 DFS 路徑的狀態」
* `i` 是「這一層的位置」

**把狀態都當參數，思路比較清楚，不容易搞混層級**

---

### 原因 2️⃣：避免不小心用到全域狀態

Subsets II 邏輯比較複雜（去重、skip）

用參數傳遞可以：

* 明確知道「這一層在用什麼狀態」
* 不會誤以為 subset 是每層獨立的

很多教學刻意這樣寫，是**為了教學安全性**。


---

## 用一句超白話比喻

### 不傳 `subset`

> 全家共用一張白板，大家輪流寫、擦

### 傳 `subset`

> 每一層明確知道「我現在用的是哪張白板」
> （但其實還是同一張）

---

## 最後一句讓記住（很重要）

> **要不要把 `subset` 傳下去不是重點，
> 重點是：是不是在「同一條 DFS 路徑」上修改同一個 list。
> Subsets I 和 Subsets II 在這一點上完全一樣。**
