```python
class Solution:
    def maxPathSum(self, root: Optional[TreeNode]) -> int:
        res = [root.val]

        # return max path sum without split
        def dfs(root):
            if not root :
                return 0
            
            leftMax = dfs(root.left)
            rightMax = dfs(root.right)

            leftMax = max(leftMax, 0) #取正值 負值會使總路徑和變小
            rightMax = max(rightMax, 0)

            # compute max path sum WITH split
            res[0] = max(res[0], root.val + leftMax + rightMax) 

            return root.val + max(leftMax,rightMax)

        dfs(root)
        return res[0]
```

# leftMax = max(leftMax, 0) 的作用

```python
       -10
       /  \
     9    20
         /  \
       15    7
```

#### 如果我們在遍歷時不做 max(leftMax, 0) 的處理，像上面的 -10 根節點，它的路徑和可能會因為負值（比如如果子樹有負值）而變得更小。但透過這行程式碼，我們保證負的路徑和會被視為 0，不會影響到最終的最大結果。
#### 例如： 如果左子樹變成了 -5 而不是 9，那麼 leftMax = max(leftMax, 0) 會將這個負數捨棄，避免影響總和。


# Max Path Sum — Split 與 Non-Split 心法

## 🎯 問題本質

求 **任意兩節點之間** 的最大路徑和（路徑不能分岔）。

---

## 🌟 觀念：每個節點有兩種路徑

### 1. **Non-Split Path（可回傳給父節點）**

只能往「左」或「右」其中一邊延伸：

```
root.val + max(leftMax, rightMax)
```

> 因為路徑不能一邊接左、一邊接右後還往上延伸（會變三叉路）。

---

### 2. **Split Path（不可回傳，只能更新答案）**

左右都走，形成一條完整路徑：

```
leftMax + root.val + rightMax
```

> 這是「最大路徑可能的形狀」，但無法往父節點傳。

---

## 🔥 遞迴框架的兩件事

### ✔ 1. 更新全域最大值（Split）

```
res = max(res, leftMax + root.val + rightMax)
```

### ✔ 2. 回傳自己的最大延伸路（Non-Split）

```
return root.val + max(leftMax, rightMax)
```

---

## 🧠 為何要分開？

* **Split → 完整路徑，但不能往上走**
* **Non-Split → 不完整，但能接到父節點**

一個是為了「更新答案」，
另一個是為了「遞迴回傳」。

---

## 🌳 ASCII 圖助記

### Split Path

```
left → root ← right
```

### Non-Split Path

```
root → max(left or right)
```
